# 📋 학원 자동 출석체크 시스템

학생이 **앱을 설치하지 않고**, **최초 1회 이름 선택(동의)만으로** 출석이 자동 기록되는 시스템입니다. 출석 방법은 세 가지를 함께 사용할 수 있습니다:

| 방법 | 학생이 하는 일 | 준비물 |
|---|---|---|
| 📌 **NFC 태그** | 문 옆 태그에 폰을 **갖다 대기만** 하면 끝 | NFC 스티커 (개당 500~1,000원) |
| 📺 **회전 QR** | 폰 카메라로 화면의 QR을 비춤 | 교실 앞 태블릿/모니터 |
| 👆 **터치 출석** | 입구 태블릿에서 자기 이름 터치 (폰 불필요) | 입구 태블릿 |

- 회전 QR은 30초마다 자동 갱신 → 캡처본 대리출석 방지
- NFC 태그와 같은 주소의 **인쇄용 고정 QR**도 제공 (화면 없이 종이만 붙여도 동작)
- 반(커리큘럼)마다 다른 학생 명단 자동 관리, 지각/결석 자동 판정
- 출석·지각·결석 시 학부모 알림 메시지가 대기열에 자동 생성 (알림톡/SMS API 연동 지점 제공)

## 시작하기

```bash
npm install
npm start
```

서버가 `http://localhost:3000` 에서 실행됩니다.

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `TEACHER_PIN` | `0000` | 선생님 로그인 PIN — **운영 시 반드시 변경하세요** |
| `DATA_DIR` | `./data` | SQLite DB 저장 위치 |

```bash
TEACHER_PIN=1234 PORT=3000 npm start
```

> 학생 폰에서 접속하려면 같은 Wi-Fi에서 학원 컴퓨터의 IP로 접근 가능해야 합니다.
> QR에 담기는 주소는 접속한 호스트 기준으로 자동 생성되므로, 키오스크 화면을
> `http://<학원PC의 IP>:3000/...` 으로 열면 학생 폰도 같은 주소로 연결됩니다.

## 사용 흐름

### 선생님 (최초 설정)
1. `http://<서버주소>:3000` 접속 → PIN 로그인
2. 반(커리큘럼) 생성 — 이름, 시간표 메모, 지각 기준(분)
3. 반 상세 페이지에서 학생 이름과 학부모 연락처 등록

### NFC 태그 설치 (1회, 선택)
1. 반 관리 페이지의 **[NFC 태그 / 인쇄용 고정 QR]** 섹션에서 주소 복사
2. 무료 앱 **NFC Tools**로 NFC 스티커(NTAG213/215)에 URL 기록 → 교실 문 옆에 부착
3. 또는 [인쇄용 QR 보기]로 QR을 출력해서 부착 (효과 동일)
4. 학생이 폰을 태그에 대면(안드로이드) / 태그에 대고 알림을 탭하면(아이폰) 자동 출석

### 매 수업
1. 반 목록에서 **[수업 시작]** 클릭 — NFC/고정 QR은 이 순간부터 해당 수업으로 자동 연결됨
2. 필요에 따라 **[QR 화면 열기]**(교실 앞) / **[터치 출석 화면]**(입구 태블릿)을 띄워둠
3. 학생들이 태그/스캔/터치하면 출석 현황 페이지에 실시간 반영 (3초 자동 새로고침)
4. 필요하면 학생별 수동 정정 (출석/지각/결석)
5. 수업 종료 시 **[수업 종료]** — 미체크 학생은 자동 결석 처리 + 학부모 알림 생성

### 학생
1. **처음 한 번**: 태그 또는 QR 스캔 → 명단에서 본인 이름 선택(동의) → 기기 등록 + 출석 완료
2. **이후**: 태그에 대거나 스캔만 하면 자동 출석. 클릭할 것 없음.
3. 폰이 없는 학생은 입구 태블릿에서 자기 이름 터치
4. 폰을 바꾸면 선생님이 반 관리 페이지에서 [재등록 허용]을 눌러줌

## 동작 원리

- **회전 QR**: `세션 ID + HMAC 토큰(30초 창)`이 담긴 체크인 URL. 토큰은 서버의
  세션별 비밀키로 생성되어 30초마다 바뀌고, 직전 창까지만 유효합니다.
- **NFC/고정 QR**: 반별 고정 토큰이 담긴 URL. 서버가 그 반의 '진행 중 수업'을 자동
  선택해 출석 처리합니다. 수업 중이 아니면 거부됩니다. (서버가 학원 내부망에만 있으면
  집에서 URL을 열어도 접속 자체가 안 되므로 원격 대리출석이 차단됩니다.)
- 학생 기기는 최초 등록 시 발급된 반별 장기 쿠키(`dt_<반ID>`)로 식별됩니다.
  이후 태그/스캔 시 서버가 쿠키 → 학생 매핑으로 자동 출석 처리합니다.
- 수업 시작 시각 + 반별 지각 기준(분)을 넘겨 체크하면 자동으로 '지각' 기록됩니다.
- 출석 기록에는 방법(`qr`/`tap`/`kiosk`/`manual`)이 함께 남습니다.

## 학부모 알림 연동

출석/지각/결석 이벤트는 `notifications` 테이블에 쌓입니다.
실제 발송은 `src/server.js`의 `queueNotification()` 안 TODO 지점에서
카카오 비즈메시지(알림톡), NHN Cloud SMS 등 원하는 API 호출로 교체하면 됩니다.

## 구조

```
src/server.js   # Express API 서버 + QR 토큰 로직
src/db.js       # SQLite 스키마 (better-sqlite3)
public/
  index.html          # 선생님: 반 목록 / 수업 시작
  class.html          # 선생님: 학생 명단·기기 관리, NFC/인쇄 QR, 수업 기록
  session.html        # 선생님: 실시간 출석 현황 + 수동 정정
  kiosk.html          # 교실용: 회전 QR 표시 화면
  tablet.html         # 입구 태블릿용: 이름 터치 출석 화면
  checkin.html        # 학생용: QR/NFC 접속 후 자동 출석 / 최초 등록
  notifications.html  # 선생님: 학부모 알림 대기열
```

## 알아둘 점 / 확장 아이디어

- **완전 무접촉(스캔조차 없는) 자동 출석**이 필요하면: 학생에게 BLE 비콘 태그(키링형,
  개당 5천~1만 원)를 나눠주고 교실에 스캐너(안드로이드 폰/라즈베리파이)를 두는 방식으로
  확장할 수 있습니다. 이 서버의 출석 API 구조(`attendance.method`)는 그대로 재사용 가능합니다.
  스마트폰만으로 앱 설치 없이 거리 기반 자동 인식하는 것은 iOS/Android의 백그라운드
  블루투스 제약 때문에 불가능합니다.
- 한 학생이 여러 반에 다니는 경우 반마다 학생을 각각 등록하세요 (기기 등록도 반별로 1회).
- 운영 배포 시 HTTPS(리버스 프록시) 사용과 `TEACHER_PIN` 변경을 권장합니다.
